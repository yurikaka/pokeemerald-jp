# Manual text-override review

Every reference override in `patch/batches/` is reviewed by hand, one by one.
Tools only enumerate entries and decode bytes for reading; every verdict is a
manual judgment.

## Per-entry checks

1. **Target is text**: the `original` address in `baserom_jp.gba` holds a
   0xFF-terminated string that decodes with the Wokann JP charmap to the
   expected Japanese text, cross-checked against the Wokann `dev` source
   label for that address.
2. **Address is a text reference**: the 4 bytes at `address` in
   `baserom_jp.gba` equal the `original` pointer, and the surrounding bytes
   show a legitimate text-reference context:
   - `0F 00 <ptr> 09` — event-script `msgbox` loadword + callstd
   - `0F 00 <ptr> 06/07/...` — other script commands taking a text word
   - a run of consecutive `08 xx xx xx` words — a pointer table
   - Thumb literal pool / `ldr` immediate in code (addresses < 0x081DABAC)
   Anything else (script bytecode without a text command, AI script, graphics
   data, struct fields) is a bug.
3. **Semantics**: the Chinese text faithfully renders the Japanese original
   (via the US Chinese source when the text was ported from the US project),
   accounting for documented deliberate deviations (removed trailing 。 in
   item descriptions, reordered placeholders, narrow-font display variants).

## Verdicts

- `ok` — text target, text reference, faithful translation
- `ok-intentional` — valid override with a deliberate, documented deviation
- `fix-text` — the Chinese text has a semantic problem
- `fix-address` — the override address/target is not provably a text reference
- `remove` — the override should not exist

## Files

- `queue.jsonl` — one record per override; `verdict`/`notes` are the manual
  review fields. Regenerated by `patch/tools/build_manual_review_queue.py`,
  which preserves existing verdicts.
- `batches/<batch>.md` — exported per-batch ledger.
- Verdicts are recorded through `patch/tools/manual_review.py`.
- `patch/tools/manual_review_sheet.py` prints per-entry ROM context bytes
  used during review.
