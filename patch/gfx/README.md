# Graphics resources

`move_types.4bpp` is the 5888-byte, 4bpp type-icon atlas generated by
`graphics/types/move_types.4bpp` in `pokeemerald_us_chs` at localization
commit `2e2ff18c5`. It contains the 18 battle types and 5 contest categories,
each as a 32 by 16 pixel icon.

The Japanese summary screen uses the same atlas size, tile order, palette, and
sprite tag. The patch compresses this resource at build time and replaces only
the `CompressedSpriteSheet.data` pointer at `0x085ED40C`.
